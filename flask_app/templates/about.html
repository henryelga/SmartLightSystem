About SmartLightSystem

Welcome to SmartLightSystem! This application automates lighting controls using sensors and allows manual overrides via a web interface. It integrates features such as motion detection, beam-breaking sensors, and manual light toggles.

Features

  • Automatic light control based on motion and beam status
  • Manual light toggling via the web interface
  • Real-time event tracking and logging
