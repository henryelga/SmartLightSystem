## About SmartLightSystem
Welcome to SmartLightSystem! This application automates lighting controls using sensors and allows to motior live-data via a web interface. It integrates features such as motion detection, beam-breaking sensors, and manual light toggles.

## Features
- Automatic light control based on motion and beam status
- Manual light toggling via the web interface
- Real-time event tracking and logging

## Live Data at a Glance
The dashboard gives you a real-time view of the current status of your smart home lighting system. You can quickly see:
- Whether motion has been detected in the monitored area
- If the IR break beam sensor is detecting any activity
- The current on/off state of the connected light
